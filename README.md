# 🏥 Asistente Inteligente para Clínicas (Streamlit + IA)

Aplicación desarrollada en Python con Streamlit que permite automatizar la atención al paciente, gestionar leads y organizar citas de forma inteligente.

---

## 🚀 Funcionalidades

- 🤖 Asistente conversacional con IA (Claude)
- 📅 Gestión automática de citas
- 📊 Visualización de leads en tiempo real
- 📂 Exportación de datos a CSV
- ✏️ Actualización del estado de leads

---

## 🧠 Tecnologías utilizadas

- Python
- Streamlit
- Anthropic (Claude API)
- Google Sheets
- Pandas

## 💡 Caso de uso

Ideal para clínicas (fisioterapia, psicología, estética…) que quieran:

- Automatizar respuestas a pacientes
- Organizar citas
- Centralizar leads
